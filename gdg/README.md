## 音源ファイルを動かさないでください

**`/dojo_loop.mp3` は絶対に移動・削除しないでください。**

8月に配布した `sketch.js` には、このURLが直接書かれています。

```js
const OTO_URL = 'https://nodatsu.github.io/gdg/dojo_loop.mp3';
```

参加者が持ち帰ったコード、共有ドキュメントに貼られたコード、
別のセミナーで配ったコード。**そのすべてがこのURLを見ています。**
動かすと、全部が鳴らなくなります。

### 同じファイルが2か所にあるのは、わざとです

8月の作業ページには、**自分の置かれた場所から音源URLを組み立てるJavaScript**が入っています。
ページを `/2026-08-09/` に移したため、そこからは `/2026-08-09/dojo_loop.mp3` を探しにいきます。

- ルートの `dojo_loop.mp3` … 配布済みコードのため(動かせない)
- `2026-08-09/dojo_loop.mp3` … 移動後のページが自動生成するURLのため

**どちらか一方を消すと、片方が壊れます。**300KBの重複ですが、残しておいてください。

## 開催のたびにやること

### 1. トップページの「今日のページ」を書き換える

`index.html` の中ほどに、コメントで囲んだ部分があります。

```html
<!-- ▼ 開催のたびに、この行き先と日付を書き換えてください ▼ -->
<a class="today" href="2026-10-03/">
  <b>今日のページ →</b>
  <span>2026年10月3日　話しかけると、返事をするものを作る</span>
</a>
<!-- ▲ ここまで ▲ -->
```

**既存のQRコードと短縮URL(`x.gd/IQh88`)はトップページを指しています。**
ここを書き換えるだけで、掲示物を作り直さずに済みます。

### 2. 「これまでの回」に1件足す

`.kai` のブロックをコピーして、日付・タイトル・一行説明・リンクを書き換えてください。
**新しい回を上に置きます。**

### 3. 新しい回のフォルダを作る

`2026-10-03/` をコピーして日付を変え、中身を差し替えます。

## なぜトップページを作ったか

8月のページを別のセミナーで教材として使われているとのことでした。
**各回のページは、単体で教材として成立しています。**
参加していない人でも、上から順に進めれば同じものが作れます。

回が増えるほど、この蓄積に価値が出ます。トップページは、その入口です。
