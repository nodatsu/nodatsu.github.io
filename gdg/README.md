# 参加者向けページ

プレ道場(2026年8月9日)当日、参加者に開いてもらうページです。
外部ライブラリは使っていません。HTML 2枚だけで完結します。

## 2つのバージョンがあります

**どちらか一方を選んで公開してください。**中身は同じで、文章量が違います。

| | `simple/` | `detail/` |
|---|---|---|
| 案内ページ | 約500字 | 約2,100字 |
| 作業ページ | 約1,560字 | 約4,190字 |
| 性格 | **読ませずに、押させる** | 読めば全部わかる |
| お題 | 1件ずつコピーボタン | 表で読ませる |
| 向いている場面 | 当日、手を動かしてもらう | 事前配布、欠席者、道場主の手控え |

### `simple/` を勧めます

当日ページを読むことに集中されると本末転倒です。simple 版は次の設計にしてあります。

- **お題も、困ったときの文も、全部コピーボタン。** 読まずに押して貼るだけで進みます
- 説明は1行まで。判断が要る話は削り、道場主が口頭で補う前提
- `p5.js Web Editor をひらく` などのリンクもボタン化
- 自分の音楽を使う手順など、少数向けの内容は折りたたみ

`detail/` は、進行台本の内容をほぼ網羅しています。事前に配る場合や、
当日来られなかった人に渡す場合はこちらが向きます。

## GitHub Pages への置き方

1. 新しいリポジトリを作る(公開)
2. 選んだフォルダの**中身**(`index.html`・`work.html`・`dojo_loop.mp3`)をリポジトリ直下に置く
3. Settings → Pages でブランチを指定して公開
4. 表示されたURLの短縮URLとQRコードを作り、当日に掲示する

**QRコードの行き先は `index.html` にしてください。**
案内ページに「作業ページをひらく」の大きなボタンがあります。
QRを2つ配ると、当日「どっちですか」が必ず発生します。

> **`完成例_道場主用/` は絶対に同じリポジトリに入れないでください。**
> リンクを張らなくても、公開された時点でURLは辿れます。
> 参加者が完成形を見ると、全員の作品がその劣化コピーになります。

置くのは次の3つだけです。

```
リポジトリ/
├── index.html      ← 案内ページ(QRの行き先)
├── work.html       ← 作業ページ
└── dojo_loop.mp3   ← 音源
```

このフォルダの構成:

```
参加者向けページ/
├── simple/     ← 当日用(推奨)
│   ├── index.html
│   ├── work.html
│   └── dojo_loop.mp3
├── detail/     ← 詳しい版
│   ├── index.html
│   ├── work.html
│   └── dojo_loop.mp3
├── dojo_loop.mp3
└── README.md
```

## 公開前にやること

`work.html` の末尾近くに、編集する場所が1か所だけあります。
URLを入れると、対応するボタンがページに現れます。**空のままだとボタンは隠れます。**

```js
const SETTINGS = {
  共有ドキュメントURL: '',   // 作品のコードを貼ってもらう Google ドキュメント
  コミュニティURL:     '',   // GDGコミュニティページ / 登録フォーム
  アンケートURL:       ''    // 当日アンケート
};
```

`detail/index.html` にも `コミュニティURL` の欄があります
(simple 版の案内ページには設定欄はありません)。

すべて空でもページは成立します。決まったものから順に入れてください。

## 共有ドキュメント(作品の記録)について

HDMI直結で投影するため、**ドキュメントは投影のためではなく「記録と持ち帰り」のため**にあります。
アカウントを作らずに作業した参加者にとって、これが唯一の記録になります。

準備すること:

- Google ドキュメントを1つ作り、**「リンクを知っている全員」を編集者**にする
- 冒頭に書き方の例を書いておく(見出し = 「名前 v3」、書式なし貼り付けを使う)
- **当日だけ公開し、終了後に共有を切る**(URLが漏れると誰でも編集・削除できます)

> **書式なし貼り付けを必ず案内してください。**
> Google ドキュメントはアポストロフィを自動変換します。ふつうに貼り付けると
> `'` が `'` になり、あとでコードを戻したときに動きません。
> Windows は `Ctrl + Shift + V`、Mac は `⌘ + Shift + V` です。作業ページにも明記してあります。

### 音源のURLは自動で入ります

参加者がコピーする `sketch.js` の中の音源URLは、**ページ自身の場所から自動で組み立てます。**

```js
const OTO_URL = 'https://<ユーザー名>.github.io/<リポジトリ名>/dojo_loop.mp3';
```

`dojo_loop.mp3` を `index.html` と同じ場所に置いておけば、書き換えは不要です。
GitHub Pages は CORS を許可しているため、p5.js Web Editor から直接読み込めます。
**参加者は音源をアップロードする必要がありません。**

ローカルでファイルを直接開いた場合(`file://`)は、相対パス `dojo_loop.mp3` のままになります。

## 設計の意図

- **暗い配色にしてあります。** ドームの部屋は暗いため、白い画面はまぶしく、
  スクリーンに余計な光が乗ります。
- **コピーボタンは3つのファイルすべてにあります。** 一部だけ書き足す方式はミスを誘発するため、
  全文の上書きに統一しています。
- **コードは折りたたんであります。** 「コードを見る」を押すと展開します。
  ページを短く保ちつつ、中身も確認できます。
- **クリップボードが使えない環境では、自動で選択状態にします。**
  ボタンの表示が「Ctrl+C でコピー」に変わります。
