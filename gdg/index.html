1準備 — 3つを貼るだけ

p5.js Web Editor を開いて、新しいスケッチを作ってください。
そこにある3つのファイルを、上から順に、全部まるごと入れ替えます。

一部だけ書き足すのではありません。エディタ側を全部選んで(Ctrl+A / ⌘+A)、 コピーしたものを貼り付けて上書きします。この順番でやってください。

STEP 1 sketch.js 作品の本体。これから作り変えていくところ
コードを見る
// 音に反応する四角 / p5.js
//
// [変更履歴] 変更するたびに、いちばん下に1行だけ追記する。
//            前の行は書き換えない。
// v1  白い四角が、音の大きさに合わせて伸び縮みする

const OTO_URL = 'dojo_loop.mp3';   // 音源の場所

let song;      // 音楽
let amp;       // 音の大きさをはかるもの
let playing = false;

function preload() {
  song = loadSound(OTO_URL);
}

function setup() {
  createCanvas(960, 540);
  amp = new p5.Amplitude();
  rectMode(CENTER);          // 四角を「中心の位置」で置く
  noStroke();
}

function draw() {
  background(0);             // 背景を黒でぬりつぶす

  // まだ音が鳴っていないときは案内を出す
  if (!playing) {
    fill(255);
    textAlign(CENTER, CENTER);
    textSize(26);
    text('画面をクリックすると音が鳴ります', width / 2, height / 2);
    return;
  }

  const oto = amp.getLevel();        // 今の音の大きさ(0〜0.3くらい)
  const ookisa = 60 + oto * 1000;    // 音が大きいほど大きく

  fill(255);
  rect(width / 2, height / 2, ookisa, ookisa);
}

// 画面をクリックしたら音を鳴らす
// (ブラウザの決まりで、一度クリックしないと音を出せません)
function mousePressed() {
  if (!playing) {
    userStartAudio();
    song.loop();
    playing = true;
  }
}

2動かす

  1. エディタの ▶(再生) を押す
  2. 「画面をクリックすると音が鳴ります」と出たら、画面をクリック
  3. 音が鳴って、白い四角が音に合わせて伸び縮みしたら成功です

ここまでできたら手を挙げてください。全員そろってから先に進みます。

3三つの鉄則

1. ひとつずつ頼む 「色を変えて、動きも速くして、形も増やして」は失敗のもと。ひとつ言って、動いたら次を言う。
2. 動いたら保存 うまくいったコードは、メモ帳などにコピーしておく。壊れても戻れます。画面を再読み込みすると消えるので要注意。
3. エラーはAIに貼る 赤い文字が出たら、全部コピーしてAIに渡すだけ。英語は読まなくていい。読むのはAIの仕事です。

6ドームで映えるコツ

作った作品は、この部屋のドームスクリーンに映します。ふつうの画面とは見え方が違うので、 次の3つを意識すると見ばえがよくなります。

コツなぜ
背景は暗く画面全体が明るいと、まぶしくて細かいところが見えなくなる
太く、大きく、ゆっくり細い線や速い動きは、大きく映すとつぶれて見えない
画面の中心を主役にドームでは、画面の中心が見上げた先にくる

AIに頼むときは「もっと大きく、ゆっくりにしてください」と言えば通じます。
