1今日ぶつかった壁

今日つくったボットは、決まった言葉が入っているかどうかだけを見ています。 だから、言い方を少し変えられると答えられなくなります。

聞き方今日のボット
ゴミの日はいつ？燃えるゴミは火曜と金曜です。　答えられた
燃えるゴミっていつ出せばいいんだっけ ゴミの分別表は市のサイトにあります。　「ゴミ」に反応したが、答えになっていない
あしたって何ゴミだっけ？ よくわかりません。　お手上げ

ルールを足せば足すほど答えられる範囲は広がりますが、言い回しは無限にあります。 書き切ることはできません。ここが、この作り方の限界です。

これは失敗ではありません。限界の場所を自分の手で確かめたということです。 ここから先に、何が必要になるのかが見えてきます。

2生成AIなら、どうなるか

同じ質問を生成AIに投げると、たとえばこうなります。

聞き方生成AI
燃えるゴミっていつ出せばいいんだっけ 燃えるゴミは火曜と金曜です。
あしたって何ゴミだっけ？ 今日は月曜なので、明日は火曜、燃えるゴミの日です。
ゴミ出すの忘れてた… 次の回収は金曜です。それまで保管をお願いします。

※ 実際の返事は毎回変わります。同じようには返りません。

何が違うのか

今日のボットは言葉が一致するかを見ていました。生成AIは意味が近いかを見ます。 大量の文章から学んだパターンをもとに、続きとして自然な言葉を選んでいます。

いちばん大きな違いは、ルールを書かなくていいことです。 代わりに「どう振る舞ってほしいか」を、日本語で書いておきます。 
あなたはむつ市役所の窓口案内係です。
ていねいな言葉で、短く答えてください。
・燃えるゴミ：火曜と金曜
・燃えないゴミ：第2・第4水曜
・分からないことは「窓口にお問い合わせください」と答えてください

これは、今日みなさんがやっていたことと同じです。 日本語でAIに指示を出す。その相手が、自分のボットの中に入るだけです。

今日「思った通りにならない」と苦労した経験が、そのまま効いてきます。 どう書けば意図が伝わるかを知っている人ほど、良いボットが作れます。

3どうやって作るのか

ボットの中から、AIのサーバーに質問を送って、返ってきた答えを表示します。 そのためにAPIキーという合鍵が要ります。

やってはいけない形

ブラウザHTML + APIキー
→
AIのサーバー
// これは絶対にやってはいけません
const API_KEY = "sk-abcd1234...";   // ← 見ようと思えば誰でも見られます

ブラウザに書いたものは、すべて読まれます。 公開されたキーを探して回るプログラムが実際に動いていて、 数日の不正利用で数万ドルの請求が発生した例が報告されています。 キーを持つのはあなたなので、使われた分の請求もあなたに来ます。

正しい形

ブラウザキーを持たない
→
自分のサーバーキーはここ
→
AIのサーバー

キーはサーバーに置いて、ブラウザからは渡しません。 こうすると、使いすぎを止めたり、記録を残したりもできるようになります。

つまり「サーバーを用意する」ところから始まります。 これが、今日の2時間では扱えなかった理由のひとつです。

要るもの実際のところ

お金 使った分だけかかります。無料枠のあるサービスもあります。 練習のうちは無料枠で足ります

年齢の条件 サービスごとに違います。次の節で説明します

5年齢の条件は、サービスごとに違います

サービス条件
Gemini API
(Google)		 18歳以上。18歳未満が使う可能性のあるものに組み込むことも認められていません

高校生のみなさんへ

「まだできない」ではなく、「順番がある」と考えてください。 今日の道場では扱いませんが、道が閉じているわけではありません。
  • Gemini の API は18歳から。大学生になれば、自分で使えます
  • OpenAI の API は13歳から。ただし保護者の許可と監督が必要です。 支払いもクレジットカードなので、おうちの人と一緒に相談してみてください
  • 学校の授業で使えるようになっている生成AIもあります。先生に聞いてみてください

そして何より、今日やったことは、その準備そのものです。 AIにどう伝えれば思った通りに動くのか。この感覚を持っている人が、いちばん良いものを作ります。 道具が手に入ったときに、すぐ走り出せます。

6窓口の案内を、本気で作るなら

むつ市の窓口対応を想定している方へ。技術よりも先に、決めることがあります。

決めることなぜ
キーを誰が持つか 従量課金なので、漏れれば請求が来ます。置き場所と管理者を先に決めます
市民の情報を送ってよいか ここが最大の論点です。氏名や住所を外部のAIに送ってよいか。 送らない設計にできるか
間違えたときどうするか 生成AIは、もっともらしい誤りを返すことがあります。 「必ず窓口で確認してください」と添えるなどの歯止めが要ります
記録をどう残すか 何を聞かれ、何と答えたか。改善にも、説明責任にも使います

スマートシティ推進戦略では、窓口改革とAIによる案内が構想に入っています。 この道場は、その実験場として使っていただけます。 小さく作って、試して、駄目なら作り直す。それが一番速い道だと思います。
